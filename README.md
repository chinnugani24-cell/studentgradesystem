# Student Grade Management System

## Description
A Java console-based application that allows users to enter a student's name and marks for three subjects. The program calculates the average marks, assigns a grade, and displays a student report.

## Features
- Input student name
- Input marks for 3 subjects
- Calculate total and average
- Assign grade (A/B/C/Fail)
- Display student report

## Technologies Used
- Java
- JDK
- VS Code

## Grading Criteria
- A : Average >= 90
- B : Average >= 75
- C : Average >= 50
- Fail : Average < 50

## How to Run

Compile:

```bash
javac StudentGradeManagement.java
```

Run:

```bash
java StudentGradeManagement
```
